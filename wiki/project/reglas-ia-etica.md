# Reglas de IA y ética

## IA (permitida, no opaca)

Se puede usar software, herramientas digitales e IA generativa si no se vulneran derechos, confidencialidad ni las bases. Si el uso es **sustantivo**, el equipo debe poder explicar función, alcance y decisiones. Declararlo en el Anexo VI.

Esta segunda memoria y Cursor cuentan como uso sustantivo.

Kenji: preferir un modelo **de la tarea** (local, de dominio) antes que pegarle una API de LLM a todo. El prototipo tiene que ser explicable en el pitch. Detalle en [IA responsable](ia-responsable.md).

## Cinco límites que él fijó para salud / texto

No diagnostica. No prescribe. No decide oportunidades. Datos sintéticos o con consentimiento. Sesgo dialectal. Humano en el loop. Urgencia por reglas, no por el clasificador.

## Descalificación

Plagio o apropiación de código/ideas (incluye **entregar el demo del taller** como si fuera propio); datos falsos; ética/seguridad; discriminación; atacar sistemas de terceros; producto hecho de antemano si las reglas lo prohíben.

## Autoría

Derechos morales a quienes crean. Recursos de terceros (HF, código de Kenji): licencia y declaración.
