# Síntesis

Tesis actual:

> El equipo **YAIS-RED** continúa como startup una experiencia de **prevención primaria de ASI**: el niño de primaria aprende jugando (límites, saludos y adulto de confianza), mientras padres y escuela aprenden a no minimizar y a derivar. El método de aula proviene del trabajo de Arianna con una ONG. El primer producto se implementa como web 3D; no diagnostica ni guarda el relato del niño.

### Continuidad posterior

Diego indica que YAIS-RED continuará como proyecto real de startup y que HACKBIZ queda como contexto histórico. La dirección de producto que se está explorando es **La Isla de los Acuerdos**, una experiencia 3D web de decisiones con antología de minijuegos. La aplicación se orienta a Vite + React + TypeScript + React Three Fiber/drei; Blender headless + GLB sigue siendo la cadena de assets. Esto no reemplaza la tesis de prevención ASI ni convierte el stack en irreversible. La historia, los niveles, diálogos, evidencia psicológica, diseño de juego y modelo de negocio están pendientes de trabajo y validación. Ver [Plan de continuidad](../project/plan-continuidad-historia-negocio.md).
