# Segunda memoria

Capa persistente entre Diego y las fuentes. Sustituye el chat que se olvida: cada ingest y cada buena query dejan páginas.

## Contrato

| Quién | Hace |
| --- | --- |
| Diego | Cura fuentes, pregunta, decide |
| Agente | Resume, cruza, archiva, hace lint |

## Señal de que funciona

- Una pregunta de producto se responde con citas a `wiki/`, no con una invención.
- Una fuente nueva toca varias páginas, no solo un resumen aislado.
- Las contradicciones quedan escritas, no escondidas.
